## Owner constraint (standing)

> "I just don't want false entry logic to be a new issue."

Enforced as: the `org.traccar.tollpricing` package never constructs or emits an `Event`, and
never writes `tc_events`, `tc_devices` or the `toll:` Redis keys. Pricing is read-only over
detection output. A test asserts the package has no reference to `Event` construction or
`Callback.eventDetected` (enforcing function to be named when written, per the standing rule
that every documented rule names its enforcer).

## What changes in `20` r2

- §3.1 hooks in `TollEventHandler` → replaced by a scheduled job (`TollPricingTask`).
- §3.2 state changes → **none**. WP1 is removed.
- §3.3 headline on the exit event → removed; `tc_toll_traversal` gains `entereventid`, `exiteventid`
  (unique on `exiteventid`), and has no `open` column — rows are written complete.
- §3.6 fragment merging → runs in the job, over consecutive pairs of the same device.
- §3.7 passage accumulation → replaced by a bounded trail read in the job (off the hot path).
- §6 WP0 spike → becomes: 407 estimator in Java, agreeing to the cent with `price_407_reference.py`.

## Open-source leverage (owner: "don't implement all logic yourself")

Surveyed 2026-11-05. Nothing open covers North American toll *prices*: OpenTollData is France-only
(AGPL-3.0); TollGuru and HERE are paid APIs (TollGuru stays an option for `21` Gap 5 B). So rate
cards remain ours (`build_rate_cards.py`). What we reuse instead of writing:

| Need | Library | Status |
|---|---|---|
| Facility polygons, point-in-polygon (Gap 2), gantry spatial index (STRtree), corridor km projection and interchange snap (`LengthIndexedLine`, Gap 7) | JTS `org.locationtech.jts:jts-core` | already a dependency (1.20.0) |
| Holiday date rules per province / state (Easter, nth-weekday, observed) | Jollyday `de.focus-shift:jollyday-core` + `jollyday-jackson`, Apache-2.0, Java 17 | to add, pinned 2.22.1 (2026-10-15; 2.24.0 is days old). Cards list the operator's holiday **keys**; Jollyday computes dates. Operator lists differ from public-holiday lists, so a card never inherits a jurisdiction's full list. |
| Map matching, toll flags per edge | Valhalla (D6) | later; replaces the 150 m gantry-pair clustering |
